# Manual do Usuario do VEREDAS

## Objetivo

Concentrar a visao funcional do produto para quem usa a plataforma como um todo, sem entrar nas especificacoes internas de implementacao do Core ou do Edge.

## Perfis cobertos

- gestor municipal;
- operador da central;
- motorista;
- monitor;
- responsavel ou acompanhante;
- suporte tecnico.

## Navegacao recomendada

1. Entender a plataforma pelo README principal do workspace: [../README.md](../README.md)
2. Ler os cenarios integrados: [docs/cenarios-teste.md](cenarios-teste.md)
3. Aprofundar nos detalhes do Core: [VEREDAS-Core/docs/README.md](https://github.com/sertaodigitalorg/VEREDAS-Core/blob/main/docs/README.md)
4. Aprofundar nos detalhes do Edge: [VEREDAS-Edge/docs/README.md](https://github.com/sertaodigitalorg/VEREDAS-Edge/blob/main/docs/README.md)

## Escopo deste manual

- conceitos gerais da plataforma;
- interacao entre cadastro central e execucao embarcada;
- responsabilidades de cada persona;
- leitura dos fluxos de atendimento, viagem e sincronizacao.

As especificacoes detalhadas de telas, endpoints, contratos e rotinas locais devem permanecer nos pacotes `VEREDAS-Core` e `VEREDAS-Edge`.
